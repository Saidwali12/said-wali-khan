# Said Wali Khan — iPhone Web App

This is a separate iPhone-focused installable web app shell. It does not modify the Android APK build or the main website files.

- Launch page: https://saidwali12.github.io/said-wali-khan/ios-app/
- Home-screen icon: the existing `saidwali-gpt-avatar.png`
- GPT service: https://saidwali-gpt.walizaad2.workers.dev/

## Install on iPhone

1. Open the launch page in Safari (not an in-app browser).
2. Tap Share.
3. Choose Add to Home Screen.
4. Keep the name “Said Wali Khan”, then tap Add.

This is an iOS Home Screen web app (PWA). A signed native IPA/App Store build is a separate later step requiring Apple signing and a macOS/Xcode build environment.
