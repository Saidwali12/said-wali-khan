۱. د براوزر له لارې لومړني معلومات

دا ازموینه د براوزر له خوا اجازه شوي معلومات ښيي؛ د Device Manager او ټولو نصب شوو ډرایورونو بشپړ بدیل نه دی.

د معلوماتو د لیدلو لپاره تڼۍ کېکاږئ.
مهم: براوزر د امنیت له امله د کمپیوټر دقیق ماډل نه شي لوستلای. د دقیق ماډل لپاره لاندې وړیا Windows تشخیصي فایل ښکته کړئ او په خپل کمپیوټر کې یې پخپله اجرا کړئ. دا یوازې معلومات لولي؛ ډرایور نه نصبوي او تنظیمات نه بدلوي.

د اجرا طریقه: فایل ښکته کړئ او په Windows کې یې په Right-click → Run with PowerShell اجرا کړئ. راپور به په Desktop کې د Saidwali-PC-Report.json په نوم جوړ شي. دا راپور بېرته لاندې پورته کړئ.

تر راپور پورته کولو وروسته به د ډرایور ستونزې دلته ښکاره شي.

۲. د خپل کمپیوټر ماډل او Windows نسخه ولیکئ

د ماډل له لیکلو وروسته تڼۍ کېکاږئ.

۳. د عامو ستونزو لارښوونې

  • Bluetooth: د Device Manager او د جوړوونکي رسمي ډرایور وګورئ.
  • Wi-Fi: د Wireless اډاپټر ماډل او Hardware ID معلوم کړئ.
  • Sound: د Audio وسیلې او د کمپیوټر د جوړوونکي ډرایور وګورئ.
  • Hotspot: د Wi-Fi اډاپټر ملاتړ، Driver او Windows تنظیمات وڅېړئ.
  • USB، Camera، Graphics او Chipset: د خپل دقیق ماډل له رسمي ملاتړ پاڼې ډرایور واخلئ.
Windows 7 او 8 زاړه سیستمونه دي؛ ځینې جوړوونکي یې نور ډرایورونه نه تازه کوي. د نامعلومو ډرایورونو اتومات نصب مه کوئ. د نصب مخکې Restore Point یا Backup جوړ کړئ.
